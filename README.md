# Praktikum PBO Pertemuan 2 — PHP

## Judul
Program Perhitungan Nilai Mahasiswa

## Tujuan
Mempraktikkan variabel, tipe data, percabangan, perulangan, dan function dasar menggunakan PHP.

## Tools
- PHP
- XAMPP atau Laragon
- Visual Studio Code
- Browser

## Cara menjalankan
1. Salin folder repository ini ke folder `htdocs` jika menggunakan XAMPP.
2. Pastikan Apache aktif dari XAMPP Control Panel.
3. Buka browser dan akses `http://localhost/tugas_pbo_pertemuan_02/`.
4. Jika nama folder diubah, sesuaikan alamat localhost.

## Fitur yang digunakan
- Variabel dengan tipe data string, integer, float, dan boolean.
- Percabangan `if/elseif/else` untuk menentukan status dan predikat.
- Perulangan `for` untuk menampilkan daftar mata kuliah.
- Function `tentukanPredikat()` untuk menentukan predikat nilai.
- HTML dan CSS sederhana untuk merapikan tampilan.

## Catatan
Silakan sesuaikan nama, NIM, kelas/program studi, nilai, dan data mata kuliah dengan data milik sendiri sebelum dikumpulkan.
